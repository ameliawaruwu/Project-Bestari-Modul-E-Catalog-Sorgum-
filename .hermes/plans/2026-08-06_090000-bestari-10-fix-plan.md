## Risks / Tradeoffs / Open Questions

1. **Item 3 (BESTARI→Sorgum)**: risiko paling tinggi — jangan sentuh localStorage keys / API contract (`bestari_*` di http.ts, authApi.ts). Kalau salah, semua user logout & cart rusak. **Default: ganti user-facing text saja.**
2. **Item 6 (status)**: opsi A (filter dropdown) lebih aman & konsisten dengan logika bisnis; opsi B (longgarkan) lebih fleksibel tapi hilangkan integritas transisi. **Perlu keputusan user.**
3. **Item 1 (gambar)**: kalau URL Google expired/403, solusi permanen = upload lokal. Ini butuh keputusan: migrasi data atau cukup ganti URL? 
4. **Item 5 (ID)**: "ID barang" ambigu — apakah order number di transaksi, atau product id di kelola produk? **Default: hilangkan keduanya**, tapi konfirmasi.
5. **Item 2 (aksi tumpuk)**: icon-only vs vertikal vs lebarkan — default icon-only (hemat ruang), tapi ini keputusan estetika.
6. **Commit per task** (sesuai instruksi user: JANGAN auto commit/push — minta izin tiap batch).
